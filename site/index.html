Your projects and AI coding tools, ready in one terminal.

Foldview. A friendly terminal home for projects, local apps, and AI coding agents. Open it and see what you're working on, what's already running, and how to start your next AI coding session. Local-first: project discovery, CLI detection, and configuration stay on your machine — no cloud sync, no accounts.

      Everything, at a glance
      
A terminal home for your projects and AI tools

      
Point pm at a folder and Foldview finds every project — anything with a package.json, .git, Cargo.toml, go.mod or pyproject.toml — plus the AI coding CLIs and local apps already on your machine.

    

    

      

        

        

          
AI terminals for the CLI you already have

          
Select a project and press a. Foldview finds the AI coding CLIs already on your machine — Claude, Codex, Gemini, and more — or you can add your own. Pick one and how many windows, 1–9, and Foldview opens and tiles that many Terminal windows in the project: opened 3 × claude. macOS only for now; an optional macOS 14+ menu-bar companion for quick access is on the way.

        

      

      

        

        

          
One key to launch any project

          
Press ↵ and the project's site opens. If the dev server is down, pm starts it in the background and opens the browser once it's up — the dashboard never closes. x stops a server pm started.

        

      

      

        

        
Launchable projects rise to the top

        
Anything with a dev or start script is tagged ● live or ○ stopped and sorts first. Everything else sinks below with a ● red dot.

      

      

        

        
Local apps, not just projects

        
Foldview also lists local web apps next to your projects — tools it detects when installed, like claude-mem, any live localhost server it discovers, and anything you pin yourself. Saved to ~/.foldview.json.

      

      

        

        
Real lines of code

        
Counts source only — skips node_modules, dist, build, .next, lockfiles and minified output. Also measures disk and node_modules size with du, so you can spot what's taking up space.

      

      

        

        
Live-localhost detection

        
The port is guessed from the framework, then probed with a real TCP connect — ● live or ○ stopped.

      

      

        

        
Git status

        
main ✱3 — branch and uncommitted-change count for every repo, instantly.

      

      

        

        
Language breakdown

        
Per-language bars so you know what each project is actually made of.

      

    

  


  
  

    

      Three steps
      
From zero to dashboard in 10 seconds

    

    

      

        
Install it globally

        
One command. Brings the pm command (plus folderpreview, project-manager and foldview) onto your PATH.

        

          $npm i -g folderpreview
          
        

      

      

        
Point it at your projects

        
Pass a folder, or run it bare to scan the current directory. It walks up to three levels deep.

        

          $pm ~/Documents
          
        

      

      

        
Navigate & launch

        
Move with the arrows, hit ↵ to open a project's site, or press a to open it in an AI terminal instead.

        

          ↑↓·↵·a
        

      

    

  


  
  

    

      Muscle memory
      
Keyboard-driven, all of it

    

    

      
↑↓jkMove up / down

      
gGJump to top / bottom

      
↵l🚦 Launch — open the site (starts the dev server if needed)

      
dStart the dev server in the background

      
xStop a dev server pm started

      
aAI terminals — open a detected or custom AI CLI in 1–9 tiled Terminal windows

      
DRun the dev server in the foreground

      
oOpen localhost without starting it

      
eOpen in $EDITOR (default code)

      
cCopy the project path to clipboard

      
/Search / filter by name

      
rRescan projects + ports

      
?qHelp · quit
