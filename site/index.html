Preview any project with one Enter key.

$ npm i -g lazyproj Copy

then pm ~/Documents — and you're in.

Everything, at a glance

A control panel for your ~/Documents

Point pm at a folder and it scans up to three levels deep for anything with a package.json, .git, Cargo.toml, go.mod or pyproject.toml.

One key to launch any project

Press ↵ and the project's site opens. If the dev server is down, pm starts it in the background and opens the browser once it's up — the dashboard never closes. x stops a server pm started.

Launchable projects float to the top

Anything with a dev or start script rises to the top — tagged ● live or ○ stopped. Projects with no server sink below with a ● red dot, so what you can actually run is always in reach.

Real lines of code

Counts source only — skips node_modules, dist, build, .next, lockfiles and minified output.

Live-localhost detection

The port is guessed from the framework, then probed with a real TCP connect — ● live or ○ stopped.

Git status

main ✱3 — branch and uncommitted-change count for every repo, instantly.

Language breakdown

Per-language bars so you know what each project is actually made of.

Size — disk + node_modules

Measured fast with du, so you can spot the 300 MB node_modules you forgot about.

Pure Node, one file

No dependencies, no network calls — a single .mjs using du for speed and a quick TCP probe for ports.

Three steps

From zero to dashboard in 10 seconds

Install it globally

One command. Brings the pm command (plus lazyproj, project-manager and folder) onto your PATH.

$npm i -g lazyproj

Point it at your projects

Pass a folder, or run it bare to scan the current directory. It walks up to three levels deep.

$pm ~/Documents

Navigate & open

Move with the arrows and hit ↵ to launch — pm opens the site, starting the dev server first if it isn't already up.

↑↓·↵
Muscle memory

Keyboard-driven, all of it

No mouse, no menus. Every action is a single keystroke.

↑↓jkMove up / down
gGJump to top / bottom
↵l🚀 Launch — open the site (starts the dev server if needed)

oOpen localhost without starting it

/Search / filter by name
rRescan projects + ports
?qHelp · quit
